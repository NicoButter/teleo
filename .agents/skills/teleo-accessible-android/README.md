# Teleo Accessible Android Engineering · v1.0.0

Reusable agent skill derived from the engineering practices of [Teleo](https://github.com/NicoButter/teleo), an open-source Android accessibility prototype by Nicolás Butterfield / Vetrabyte.

- **Entry:** `SKILL.md` (Agent Skills frontmatter + procedural instructions).
- **References:** audit rubric, practical Compose patterns and a report template.
- **License:** this directory is covered by Teleo's root MIT license.
- **No secrets, runtime scripts, executable dependencies, network services or bundled recordings**.
- **Claims:** an assistant's static analysis is not a certification; physical-device and user testing remain necessary.

To package the skill, archive the `teleo-accessible-android/` directory and ensure `SKILL.md` exists at its root within the archive, or package its contents directly according to the destination marketplace's ZIP requirements. Review the target marketplace's terms and ZIP layout first.
